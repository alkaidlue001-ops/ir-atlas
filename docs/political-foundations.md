# 从手写笔记到政治学知识树

素材是 Alkaid 本次提供的两页笔记。正文采用编辑性转述和扩展，并非逐字抄录；辨认不清的字句没有当作确定引文。原始笔记照片不上传到公开站。

新增独立的“政治学基础”入口和“知识树”页，把原有国际关系、马克思主义与全球治理、经济学连接起来。图谱从67个节点、65条关系扩展到88个节点、97条关系。新增21个文献／思想节点，涉及19位新学者及已有的马克思／恩格斯；同一作者可以有不同作品节点，既有人物没有复制成新的头像资料。

## 知识树的9个问题分支

1. 政治是什么：善好生活、分配、权威性分配、权力关系。
2. 国家为什么成立：自然状态、契约、主权、人民主权。
3. 统治为什么被接受：正当性、合法性、国家能力、伦理生活。
4. 权力为什么需要边界：自然权利、有限政府、分权、正义。
5. 到底谁在统治：阶级、政治精英、寡头化、多头政体。
6. 权力怎样运作：可见决策、议程控制、偏好形成、规训。
7. 国家怎样形成：战争与汲取、国家形成、国家建构、民族建构。
8. 怎样走向国际关系：无政府与国际社会、治理、霸权、结构性与网络权力。
9. 怎样做研究：问题、机制、概念操作化、比较与反证。

每支4个概念，共36项；每项具有定义、易混点、明确标为思考实验的案例／假设、练习题及关联文献。三组对照表分别比较霍布斯／洛克／卢梭、国家形成／国家建构／民族建构／正当性，以及四种国际关系视角。学习路线分三轮；支持检索、展开／收起、跳转图谱和导出完整Markdown。

知识树正文以中文讲解，重要术语中英对照；导航与操作支持中英日韩。新增图谱节点另有完整的四语标题、短概括与导读；新增关系说明目前为中文。现有后台目录也加载新增节点。知识树的长篇中文正文不会被粗略机器替换成其他语言。

## 对笔记的关键校正

| 容易压缩成的说法 | 整理后的区分与原典定位 |
| --- | --- |
| 古代 polis 就是现代国家 | 亚里士多德《政治学》第一卷：城邦与善好生活；古代政治共同体不直接等于领土主权国家。 |
| 霍布斯就是交出所有权利 | 《利维坦》第13、17、21章：自然状态、相互授权和臣民自由；自我保存仍有边界意义。 |
| 洛克的财产权只指财富 | 《政府论》第二篇第7、9、19章：政治社会、政府目的、信托与政府解体；生命与自由也属于保护议题。 |
| 公意就是多数人的意愿 | 卢梭《社会契约论》第一卷第6章、第二卷第1—3章：人民主权、共同利益、公意与众意的差别。 |
| 分权等于划出三个机构 | 孟德斯鸠《论法的精神》第十一卷第6章：关注权力制约和自由的制度安排。链接选择含第十一卷的完整卷一，避免只含第一至第五卷的节选。 |
| 黑格尔只是在赞成现存国家 | 《法哲学原理》第142—157、182、257节起：伦理生活、家庭、市民社会与国家的制度关系；解释和规范评价须分开。 |
| 马克思主义就是经济决定一切 | 《德意志意识形态》“费尔巴哈”部分：现实个人、生产与交往关系；手稿1845—1846，图谱用完整版本1932年出版年份。 |
| 韦伯的正当性意味着道德正确 | 《以政治为业》国家定义与支配讨论；正当性信念是社会学观察，不等于研究者的道德赞同。其传统／魅力／法理支配分类还需参读《经济与社会》。 |
| 施米特的例外与敌友区分是同一本书 | 《政治神学》1922讨论例外决断；敌友区分另见《政治的概念》。决断理论不自动证明无限权力正当。 |
| 民主只看是否投票／无人抗议就无权力 | 达尔《多头政体》区分公共竞争与包容参与；卢克斯《权力：一种激进的观点》扩展到议程与偏好。 |
| 国家形成与民族建构是同一件事 | 国家形成解释历史性权力集中，国家建构讨论组织能力建设，民族建构讨论认同与边界；三者关联但不等同。 |
| 国际无政府就是混乱／治理就是世界政府 | 连接沃尔兹、布尔、罗西瑙、奥斯特罗姆：区分中央权威缺位、国际社会规则与多中心协调。 |

新增的32条关系逐条带说明；多数使用“跨科对话”表达编辑性比较，不把共同问题当成直接影响或线性思想进步的证据。

## 来源和年份

所有新增节点的来源URL均在 `dist/politics.js`；知识树引用节点ID，共享相同来源。入口包括原典全文、原版扫描、文章DOI和出版社书目。出版社简介与书目只用于核对作品、版本和出版信息，不能替代逐页文本引证；此处的章节定位是进一步阅读路线。

亚里士多德约公元前350年；《君主论》写于1513年、首版1532；洛克1689发行而标题页1690；边沁1780印成、1789出版；莫斯卡1896意大利文、1939英文扩充版；米歇尔斯1911德文、1915英文；福柯1975法文、1977英文。避免把电子上线日期当原著出版年份，也避免把出版年份当思想形成的精确时间。

原典入口示例：[亚里士多德](https://classics.mit.edu/Aristotle/politics.html)、[霍布斯](https://www.gutenberg.org/ebooks/3207)、[洛克](https://www.gutenberg.org/ebooks/7370)、[卢梭](https://www.gutenberg.org/ebooks/46333)、[孟德斯鸠](https://oll.libertyfund.org/titles/montesquieu-complete-works-vol-1-the-spirit-of-laws)、[边沁](https://www.econlib.org/library/Bentham/bnthPML.html)、[黑格尔](https://www.marxists.org/reference/archive/hegel/prindex.htm)、[马克思／恩格斯](https://www.marxists.org/archive/marx/works/1845/german-ideology/)、[达尔的权力论文](https://doi.org/10.1002/bs.3830020303)、[蒂利的国家形成章节](https://www.cambridge.org/core/books/abs/bringing-the-state-back-in/war-making-and-state-making-as-organized-crime/7A7B3B6577A060D76224F54A4DD0DA4C)。
